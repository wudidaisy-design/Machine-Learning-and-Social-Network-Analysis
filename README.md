# Machine Learning and Social Network Analysis

**Coursework Project | Python Data Analysis**

This project explores machine learning, association rule mining, and social network analysis using Python.

### Key Tasks

- **Classification:** Applied Gaussian Naive Bayes and Random Forest to the Cylinder Bands dataset. Evaluated model performance using accuracy, precision, recall, F1-score, confusion matrices, and ROC-AUC.
- **Association Rule Mining:** Used the Apriori algorithm to identify purchasing patterns and relationships among product categories.
- **Social Network Analysis:** Constructed co-authorship and citation networks using NetworkX, analyzing network properties and node centrality.

### Tools

Python, Pandas, NumPy, Scikit-learn, MLxtend, NetworkX, Matplotlib, Seaborn.

### Repository Contents

Jupyter Notebook with code, analysis, and visualizations.
